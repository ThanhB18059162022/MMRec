# Các bước chuẩn bị trước khi train model

## Train model cần 4 file (trong các bước đã tạo ra)

- *.inter (data baby thì là baby.inter)
- text_feat.npy
- image_feat.npy
- user_graph_dict.npy

## Kiểm tra lại cái file trong thư mục src/config coi đúng các trường không

Khi chạy xong các bước sẽ có copy_data_to_train.ipynb để copy các file đã tạo vào thư mục data ngoài để train model
